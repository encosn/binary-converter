# 10진수 → 2진수 변환 실습기

중학교 **정보** 2단원(데이터) 수업용 웹앱입니다.
10진수를 2진수로 바꾸는 과정을 표로 **한 단계씩** 보여 줍니다.

**👉 https://encosn.github.io/binary-converter/**

- 대상: 중학교 1학년 (처음 배우는 상황)
- 연결 성취기준: **[9정02-01]** 실생활의 데이터가 디지털 형태로 변환되어 활용되는 긍정적 가치를 탐색하고, 다양한 데이터를 디지털 형태로 표현한다.
- 전체 활동 목록: **[중학교 정보 수업 활동](https://encosn.github.io/encosn/)**

## 기능

| 탭 | 내용 | 상태 |
|:---|:---|:---|
| ① 2로 나누는 방법 | 2로 나누어 나머지를 거꾸로 읽는 과정 시각화 + 연습문제 + 정답 확인 | 완성 |
| ② 더 쉬운 방법 | 자리값(128 64 32 16 8 4 2 1)으로 찾는 방법 | 준비 중 |

## 로컬에서 보기

외부 의존성이 없어 `index.html` 을 그냥 더블클릭해도 열립니다. 개발 서버로 보려면:

```
npm install
npm start        → http://localhost:8080
npm run build    → dist/
```
